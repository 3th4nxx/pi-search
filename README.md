π Search

A fast and simple tool for searching through 1,000,000 digits of π.

🔎 Features
Search any sequence of digits
Find the exact position where the sequence appears
Supports up to 1 million digits of π
Fast searching
Hacker-style animated interface
Displays matching digits clearly
Simple and lightweight
🚀 How to Use
Open π Search.
Enter a number sequence, such as:
14159
Press Search.
π Search checks the 1,000,000 digits of π.
If found, it shows the position of the sequence.
📊 Example

Search:

14159

Result:

Found!
Position: 1
Match: 14159
🧠 How It Works

π Search stores the first 1,000,000 digits of π and searches through them for the number sequence you enter.
